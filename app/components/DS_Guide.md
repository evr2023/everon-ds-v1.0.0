## 요약

DS Guide v1.0 본문에서 **8건의 오류·불일치**를 발견하여 7건을 수정 반영했고, 추가로 **3건의 검토 권고**를 별도 정리했다. 핵심 오류는 (1) DS 자체 명명 규칙(4.3 PascalCase) 위반인 표지 문서번호, (2) 4.1 토큰의 팔레트 외 색상값 사용, (3) D-06 ↔ 3.5 의 아이콘 정책 충돌, (4) D-09 챕터 참조 오류였다.

## 적용 완료 수정 (8건)

### F-01 · 표지 문서번호 — 4.3 명명 규칙 위반
- **위치**: 표지 메타 표 / 4.3 파일명 규칙
- **문제**: `EVR-DS-GUIDE-v1.0` (GUIDE 전부 대문자) — 4.3 규칙은 PascalCase('Guide')
- **근거**: 4.3 "이름: PascalCase-하이픈 (예: Figma-Specbook, QA-SOP)"
- **수정**: `EVR-DS-GUIDE-v1.0` → `EVR-DS-Guide-v1.0`

### F-02 · 1.3 배포 채널 구분자 누락
- **위치**: 1.3 "배포 채널" 문단
- **문제**: `design-tokens.json   everon-icons.woff2 · pptx/keynote` — 첫 두 항목 사이 구분자 없이 공백 3칸
- **수정**: 가운데점 추가 → `design-tokens.json · everon-icons.woff2 · pptx/keynote`

### F-03 · 4.1 토큰 색상값 — 팔레트 미정의 색
- **위치**: 4.1 디자인 토큰 예시
- **문제**: `color-text-default = #111111` — `#111111`은 2.2 핵심 팔레트 8색에 없음. Neutral Dark = `#1A2C5B`가 "본문 강조 / 표 헤더"로 정의되어 있어 토큰과 불일치
- **수정**: `#111111` → `#1A2C5B` (Neutral Dark 토큰 일치)
- **부가 효과**: 3.2.1 Card의 `shadow-card = "0 2px 8px rgba(17,17,17,0.06)"`는 그림자 전용 색이므로 그대로 유지(텍스트 토큰과 분리)

### F-04 · D-09 챕터 참조 오류
- **위치**: 6장 금지사례 D-09 "근거" 셀
- **문제**: `1.3 · 3.4` — 1.3은 "버전 관리 및 배포 원칙"으로 차트 축 비교와 무관
- **올바른 근거**: 2.1 Credibility "비교는 동일 기준" + 3.4 차트 메타
- **수정**: `1.3 · 3.4` → `2.1 · 3.4`

### F-05 · D-04 KPI 숫자 사이즈 범위 불일치
- **위치**: 6장 금지사례 D-04 "올바른 적용" 셀
- **문제**: `36–72pt` — 2.3 Number(32–72pt)와 하한 불일치. D-04는 2.3을 첫 근거로 제시하면서 2.3 하한(32)을 따르지 않음
- **수정**: `36–72pt` → `32–72pt` (2.3 Number 범위와 일치)
- **참고**: 3.2.1 KPI 카드 한정 사양은 36–56pt 유지(특수 케이스). D-04는 일반 룰을 인용하므로 2.3 범위가 적절

### F-06 · 부록 C Figma Library 명칭 불일치
- **위치**: 부록 C 리소스/배포 링크 표
- **문제**: 1.3에서 라이브러리명을 `everon-ds`로 정의했으나, 부록 C에는 `figma.com/@everon_develop / Design system`으로 표기 — 라이브러리명 'Design system' ↔ 'everon-ds' 불일치
- **수정**: `... / Design system` → `... / everon-ds (Design system)` — 1.3과 동일한 식별자 노출 + 사람이 읽는 부제 병기

### F-07 · D-06 ↔ 3.5 아이콘 정책 자체 모순 (해소)
- **위치**: 6장 금지사례 D-06 "올바른 적용" 셀
- **문제**: D-06 "DS 아이콘셋(everon-icons) 단일 사용"과 3.5 "ISO 7010 기반 + 에버온 DS 아이콘셋 2종만 혼용 허용"이 정면 충돌
- **수정**: D-06 본문에 예외 명시 추가  
  → `DS 아이콘셋(everon-icons) 단일 사용. 단, 3.5 사이니지·안전표지의 ISO 7010 픽토그램은 예외 허용`

### F-08 · 2.5.1 아이콘 규칙 — 동일 충돌의 원인 조항 보정
- **위치**: 2.5.1 아이콘
- **문제**: D-06과 동일한 모호함의 원인. "DS 아이콘셋 외부 아이콘 혼용 금지"가 3.5와 충돌
- **수정**: 예외 조항 명시  
  → `DS 아이콘셋(everon-icons) 외 외부 아이콘 혼용 금지(3.5 사이니지의 ISO 7010 픽토그램은 예외)`

## 검토 권고 (미수정 — 의사결정 필요)

### R-01 · D-10 / D-11 챕터 참조 부정확
- **현재**: D-10(로고 변형 금지) 근거 = `1.3`, D-11(개인정보 마스킹) 근거 = `1.1 예외 조항`
- **이슈**: 1.3은 버전 관리, 1.1 예외 조항은 법령 우선 규정 — 직접적 연관성 약함. 본 가이드에는 **로고 가이드라인**과 **데이터/프라이버시 정책** 섹션이 부재
- **권고**: v1.1 또는 별책 부록으로 다음 추가
  - `2.6 로고 가이드라인` (변형 금지·최소 크기·여백·컬러 룰 — D-10의 명시 근거)
  - `7.B' 데이터·프라이버시 정책` (스크린샷 마스킹·내부 수치 처리 — D-11의 명시 근거)
- 임시로 D-10/D-11 근거를 "별책 Brand Logo Guide / 데이터 가이드(예정)"로 표기 가능

### R-02 · `color-border-light` 토큰 미정의
- **현황**: `#E5E7EB`이 3.1.1 Button(disabled 테두리), 3.2.1 Card 테두리, 3.3.1 Header 하단 라인 등 다수에서 사용되나 2.2 팔레트와 4.1 토큰 어디에도 정의되지 않음
- **권고**: 4.1 토큰에 `color-border-light = #E5E7EB` 신규 정의, 2.2 팔레트 9번째 색으로 등재
- **영향도**: MINOR (기존 사용처 호환 유지)

### R-03 · 3.2.1 KPI 사이즈(36–56) vs 2.3 Number(32–72) 의도 명확화
- **현황**: 두 사이즈 범위가 다름. 의도(KPI는 카드 내 제약, Number는 일반)가 본문에 명시되지 않음
- **권고**: 3.2.1에 한 줄 추가 — "KPI 카드 내 핵심 숫자는 카드 면적에 맞춘 36–56pt 사용. IR/제안서 등 카드 외 환경의 큰 숫자는 2.3 Number(32–72pt) 적용"

## 자체 모순 / 스타일 비일관 (참고)

| # | 항목 | 본문 규정 | 본문 사용 |
|---|---|---|---|
| S-01 | 숫자-단위 띄어쓰기 (2.3.1) | "숫자·단위 사이 좁은 공백" | 본문 전반 `97%`, `64px` 등 공백 없음 |
| S-02 | SemVer 표기 | 1.3 `MAJOR. MINOR. PATCH` | 표준은 `MAJOR.MINOR.PATCH`(공백 없음) |

권고: 한국어 디자인 문서 관행상 `97%` 무공백을 허용하도록 2.3.1 단서 추가, SemVer는 표준 표기 `MAJOR.MINOR.PATCH`로 정정, 2.4 단위는 매체별 차이가 본질이므로 그대로 두되 표 캡션에 명시.
